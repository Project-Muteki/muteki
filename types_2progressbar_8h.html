enum ui_progressbar_flag_e

Progress bar style flags.

Enumerator
UI_PROGRESSBAR_FLAG_NONE 

Default look (flat, no percent label).

UI_PROGRESSBAR_FLAG_SHOW_PERCENT 

Add a percent label in the middle of the progress bar.

UI_PROGRESSBAR_FLAG_SEGMENTED 

Segmented mode.

UI_PROGRESSBAR_FLAG_GRADIENT 

Add a gradient texture (white -> widget fg color) to the progress bar.

Note
This does nothing if the progress bar is in segmented mode.

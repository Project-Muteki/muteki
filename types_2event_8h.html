◆ ui_event_component_call_e

enum ui_event_component_call_e

Internal UI component call request types.

These values may go into the ui_event_t::value field when ui_event_t::event_type is UI_EVENT_TYPE_COMPONENT_CALL.

Enumerator
UI_EVENT_COMPONENT_CALL_ERASE_BG 

Erase the background of the component.

This runs the ui_component_s::on_erase_bg callback.

UI_EVENT_COMPONENT_CALL_DRAW 

Draw the component.

This runs the ui_component_s::on_draw callback and sets the ui_event_sys_s::user_data to 0x5a5a5a5a.

UI_EVENT_COMPONENT_CALL_SET_STATE 

Set state.

This runs the ui_component_s::on_set_state callback with the mask and set value set in the event.

Warning
The event format must be the extended ui_event_state_change_t, which is 4 bytes larger than the standard ui_event_t, and having the parameters that will be passed to ui_component_s::on_set_state packed into the ui_event_state_change_t::state_change property.
See also
ui_event_state_change_t::state_change

◆ ui_event_internal_e

enum ui_event_internal_e

Internal system UI event types.

These values may go into the ui_event_t::value field when ui_event_t::event_type is UI_EVENT_TYPE_INTERNAL.

Unlisted values behave similarly to UI_EVENT_INTERNAL_FLAG.

Enumerator
UI_EVENT_INTERNAL_FLAG 

Set a flag but do not queue the event.

UI_EVENT_INTERNAL_BATTERY_CHECK_REQUEST 

Request GetEvent() to do a low battery check.

UI_EVENT_INTERNAL_BYPASS 

Queue this event normally into the system event queue. Exact purpose is unclear.

◆ ui_event_source_e

enum ui_event_source_e

Event source.

Describes how the event is produced and where it is being produced.

Note
This can be unreliable sometimes as certain functions like PutEvent() have rules that bypass this value.
Enumerator
UI_EVENT_SOURCE_SYSTEM 

Event is a system event (from the system event queue).

UI_EVENT_SOURCE_SEND_MESSAGE 

Event is a message (produced via SendMessage()).

UI_EVENT_SOURCE_PUT_EVENT 

Event is a regular event and not a UI_EVENT_TYPE_KEY or UI_EVENT_TYPE_SPECIAL (from the main event queue).

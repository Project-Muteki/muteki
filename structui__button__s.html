◆ content_layout

unsigned int ui_button_s::content_layout

Text layout of the button label.

This is most likely not intended to be set by the end-user, as the resulting layouts enabled by values other than the default look broken on the default button style, and both the default constructor and all public methods never allowed the user to set it.

enum ui_deskbox_flag_e

Deskbox style flags.

Enumerator
UI_DESKBOX_FLAG_NONE 

No flag.

UI_DESKBOX_FLAG_CLOSE_BUTTON 

Add a close button to the title bar.

Note
Some systems may suppress this.
UI_DESKBOX_FLAG_DONE_BUTTON 

Add a done button to the title bar.

UI_DESKBOX_FLAG_SAVE_BUTTON 

Add a save button to the title bar.

UI_DESKBOX_FLAG_HELP_BUTTON 

Handle help key presses.

Note
This does not add a button, instead it adds a hook to the deskbox event handler that opens the help menu.
UI_DESKBOX_FLAG_FUNCTION_MENU_BUTTON 

Add a function button to the title bar.

UI_DESKBOX_FLAG_STYLE_NORMAL 

Normal style (with title bar).

UI_DESKBOX_FLAG_STYLE_NONE 

Do not draw title bar and frame.

UI_DESKBOX_FLAG_STYLE_SIMPLE 

Draw a simple frame.

Implies UI_DESKBOX_FLAG_STYLE_NONE.

UI_DESKBOX_FLAG_STYLE_FLOAT 

Create a floating window deskbox.

UI_DESKBOX_FLAG_STYLE_POPUP 

Create a popup deskbox.

UI_DESKBOX_FLAG_NO_CLOSE_BUTTON 

Inhibit close button creation.

This takes priority over UI_DESKBOX_FLAG_CLOSE_BUTTON.

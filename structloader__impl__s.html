◆ get_module

void *(*) loader_impl_s::get_module(const char *pathname)

Retrieve an already loaded module from the global module table.

This will not attempt to open any module and instead will set the errno to BXC_ERRNO( ::BXC_ERRNO_NS_EXEC, ::BXC_ERR_EXEC_MODULE_NOT_LOADED) and return NULL if the module is not already loaded.

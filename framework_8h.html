enum ui_component_flag_e

Component behavior flag. Usually set by the component constructors but can sometimes change over time.

Enumerator
UI_COMPONENT_FLAG_SELECTABLE 

Component is selectable.

Affects the group child selection through PGROUP_setCurrent() and input event processing. Setting this bit to 0 blocks the above 2.

UI_COMPONENT_FLAG_FOCUS_TERMINAL 

Component is a terminal node when resolving focusable items in a container.

When a container is finding a component that will gain focus, stop the search immediately and select this component.

UI_COMPONENT_FLAG_FOCUS_SKIP 

Skip this component when searching for the next component to gain focus.

UI_COMPONENT_FLAG_DESKBOX_ALLOW_HOME_KEY 

Deskbox-specific: Bubble KEY_HOME presses to system.

Requires ::UI_DESKBOX_FLAG_ALLOW_SYSTEM_EVENTS to properly work.

UI_COMPONENT_FLAG_DESKBOX_ALLOW_SYSTEM_EVENTS 

Deskbox-specific: Handle system events and exit word.

UI_COMPONENT_FLAG_GROUP_ALLOW_EXIT_WORD 

Group-specific: Handle exit word.

UI_COMPONENT_FLAG_DESKBOX_ALLOW_SEARCH_KEYS 

Deskbox-specific: Bubble translator and search key presses to system.

UI_COMPONENT_FLAG_DESKBOX_ALLOW_INLINE_SEARCH 

Deskbox-specific: Invoke the inline search modal with the selected text instead of the normal search modal on KEY_SEARCH key presses.

UI_COMPONENT_FLAG_GROUP_NO_AUTO_DRAW 

Group-specific: Do not periodically draw this group.

UI_COMPONENT_FLAG_DESKBOX_ALLOW_APP_KEYS 

Deskbox-specific: Bubble app key presses to system.

unsigned short ui_event_ext_s::event_source

Seems to be tied to where the event comes from.

Set to 1 in SendMessage() events, 2 in PutEvent() events that is of neither the UI_EVENT_TYPE_KEY type or the 0x20 type. Otherwise it would usually be 0.

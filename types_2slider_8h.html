enum ui_slider_flag_e

Style flags for the slider widget.

The default slider styles.

Note
These documented behaviors are only true on an unthemed slider widget. Theme modules could ignore or drastically alter the behavior of the flags.
Enumerator
UI_SLIDER_TRACK_SIMPLE 

Track style: Simple.

This draws a thin bar filled with foreground color.

UI_SLIDER_TRACK_BAR 

Track style: Progress-bar-like.

This draws a thick bar with left portion up to the thumb filled with foreground color, and the right portion filled with background color, like a typical progress bar.

UI_SLIDER_THUMB_NONE 

Thumb style: Hidden.

UI_SLIDER_THUMB_BITMAP 

Thumb style: Bitmap.

UI_SLIDER_THUMB_BITMAP_ALT 

Thumb style: Bitmap (alternate).

Seems to be exactly the same as UI_SLIDER_THUMB_BITMAP, although an external theme could make use of it.

UI_SLIDER_THUMB_OUTLINE 

Thumb style: Outline.

Draw a black box over the thumb when it is not in focus. No idea why it is here.

UI_SLIDER_FRAME_NONE 

Frame style: None.

Do not draw a frame around the slider.

UI_SLIDER_FRAME_RAISED 

Frame style: Raised.

Draw a raised 3D-looking box frame around the slider.

UI_SLIDER_FRAME_SUNKEN 

Frame style: Sunken.

Draw a sunken 3D-looking box frame around the slider.

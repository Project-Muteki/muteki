Detailed Description

Common struct subset shared across system and main events.

This is the event struct used by GetPenEvent() and PutSystemEvent().

◆ recipient

ui_component_t* ui_event_sys_s::recipient

Event recipient.

If set to NULL, the event is a broadcast event (e.g. input event). Otherwise, the widget's ui_component_t::on_event callback will be called with this event.

◆ PGROUP_execute()

int PGROUP_execute ( ui_group_t *  self)
extern

Execute a group container.

This starts a local event loop that synchronously checks for new events using GetEvent(), dispatches any received events to its children, and checks the ui_group_t::execution_result for any non-zero return values.

When the container allows exit word processing and the exit word has been set to a non-zero value, the execution may terminate early with an execution result of 0.

Syscall Number
0x10170
Parameters
selfThe group object.
Returns
Return value of the execution.

Detailed Description

UI component group/container struct.

This is implemented as a singly-linked ring of components.

◆ execution_result

int ui_group_s::execution_result

Execution result.

The default ui_group_s::on_exec implementation will keep executing until this value is no longer 0, or exit word is allowed and has been set to a non-zero value. Thus a value of 0 returned by ExecView() indicates that the execution has been interrupted by an exit word.
